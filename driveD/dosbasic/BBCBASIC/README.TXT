To install BBC BASIC (86) Plus from Microsoft Windows:

1. Click on START.

2. Click on RUN.

3. Enter A:\SETUP and click on OK.


To install BBC BASIC (86) Plus from MS-DOS:

1. Create a directory, e.g. C:\BBCBASIC, to hold the BBC BASIC  distribution 
   files:
               MKDIR C:\BBCBASIC

2. Copy the contents of this diskette into the chosen directory:

               COPY A:\BBCBASIC\*.* C:\BBCBASIC /V

3. Add  the  chosen directory to your PATH, so that the executables  can  be 
   found:

               SET PATH = %PATH%;C:\BBCBASIC

   (you may want to make this permanent by editing your AUTOEXEC.BAT file).


To run BBC BASIC (86) type BBCBASIC (for the small memory model version)  or 
BIGBASIC  (for the large memory model version).  To exit BASIC type *BYE  or 
*QUIT.  For details please read the documentation file BBCBASIC.TXT.
